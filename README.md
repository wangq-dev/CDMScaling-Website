# What Transfers from Text to Vision?

Project website for **Capability Scaling Laws and Transfer Dynamics for VLMs**.

[Website](https://wangq-dev.github.io/CDMScaling-Website/) · [Paper](https://arxiv.org/abs/2608.00013)

## Local development

Requires Node.js 22 and npm.

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

Static files are generated in `out/`. Pushing to `main` triggers GitHub Pages deployment.
